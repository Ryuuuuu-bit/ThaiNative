# ThaiNative Online – ไทยเนทีฟ ออนไลน์

เกม RPG บนเว็บเบราว์เซอร์ มุมมอง 2D Side-scroller ธีมผีไทย
สร้างด้วย **Phaser 3** (HTML5 Canvas/WebGL), JavaScript (ES Modules) และ CSS
ส่วนออนไลน์ใช้ **Node.js + Express + Socket.io**

## วิธีรัน

ต้องติดตั้ง Node.js 18 ขึ้นไป

```bash
npm install
npm start          # หรือ npm run dev (รีสตาร์ตอัตโนมัติเมื่อแก้โค้ด server)
```

จากนั้นเปิด <http://localhost:3000> ถ้าเปิดหลายแท็บหรือหลายเครื่องใน LAN (`http://<IP เครื่อง>:3000`) จะเห็นกันแบบ real-time

## ระบบออนไลน์

```
Client A ──player:update (15Hz)──►  Server  ──world:snapshot (15Hz)──► ทุก Client
         ◄──world:init / player:joined / player:left / chat ──
```

- Server เก็บตำแหน่งผู้เล่นทุกคน จำกัดระยะเคลื่อนที่ต่อช่วงเวลา (กันวาร์ป) และตรวจค่ารูปลักษณ์ที่ส่งมา
- Client แสดงผู้เล่นอื่นย้อนหลัง 100ms แล้ว interpolate ระหว่าง snapshot ให้เคลื่อนที่ลื่น
- ตอนนี้มอนสเตอร์และการต่อสู้ยังคำนวณฝั่ง client (แต่ละคนเห็นผีของตัวเอง)
  ขั้นต่อไปคือย้าย AI มอนสเตอร์และการคำนวณดาเมจไปไว้ที่ server เพื่อให้ตีผีตัวเดียวกันได้และกันโกง

## ระบบ MMO: ปาร์ตี้ · เทรด · เรดบอส (server/social.js + client/js/systems/Social.js)

- **ปาร์ตี้** สูงสุด 4 คน – เชิญจากหน้าต่าง P หรือคลิกที่ตัวผู้เล่น · ฆ่าผีแล้วเพื่อนที่อยู่ห่างไม่เกิน 500 ได้ EXP 60% ·
  กรอบ HP สมาชิกใต้กรอบผู้เล่น · ชื่อเพื่อนเป็นสีเขียว · แชทปาร์ตี้พิมพ์ `/p ข้อความ`
- **เทรด** – server เป็นคนกลาง: ยื่นของ/เงิน → ทั้งคู่กด "ล็อก" → ทั้งคู่กด "ยืนยัน" → แลกพร้อมกัน
  (แก้ข้อเสนอเมื่อไหร่ การล็อกจะถูกปลดทั้งสองฝ่าย) ต้องยืนใกล้กัน
- **เรดบอส พญายักษ์ทมิฬ** ที่ลานพญายักษ์ (ตะวันออกสุด X ≥ 3650) – server คุม HP/AI/ท่าโจมตี ทุกคนตีตัวเดียวกัน
  - ท่า: กระบองทุบธรณี (หน้าบอส) · คลื่นแผ่นดินแยก (กระโดดหลบ) · คำรามอสูร (มึนงง) · ห่าไฟนรก (ลูกไฟตกตามตำแหน่ง) – มีวงเตือนก่อนลง
  - HP < 30% คลั่ง (เร็วขึ้น แรงขึ้น) · HP เพิ่มตามจำนวนผู้เล่นในลาน · เกิดใหม่ทุก 2 นาที
  - รางวัลตามสัดส่วนดาเมจ (EXP, เงิน, ยา, เขี้ยวพญายักษ์, โอกาส 20% ได้ "ยันต์ทองพญายักษ์")
  - ทดสอบเร็ว: `RAID_SPAWN_MS=2000 RAID_HP=3000 npm start`

## กลางวัน–กลางคืน · เซียมซี · ศาลพระภูมิ · อีเวนต์ผีห่า

- **เวลาในเกม** (shared/data/world.js, client/js/systems/Clock.js) – 1 วัน = 20 นาทีจริง ซิงก์นาฬิกา server ทุกคนเห็นฟ้ามืดพร้อมกัน
  - กลางคืน: ผีโจมตีแรงขึ้น 25% แต่ EXP x1.5 เงิน x1.3 · **กระสือ/ผีพราย ออกเฉพาะกลางคืน** · มีหิ่งห้อย แสงตะเกียง
  - ทุก 8 วันในเกม: 🌕 คืนเดือนเพ็ญ (วันพระ รางวัล x1.5) / 🌑 คืนเดือนดับ (ผีดุสุด EXP x2)
  - เพลงเปลี่ยนตามเวลา: หมู่บ้านกลางวัน/กลางคืน, ทุ่งกลางวัน/ป่าผีกลางคืน · ทดสอบ: `DAY_MS=120000 npm start`
- **เซียมซี** – ยืนหน้าวัดบางผีกด F · วันละ 1 ครั้ง · 12 ใบ ได้พรถึงเที่ยงคืน (ใบร้ายก็มี แก้เคล็ดที่ศาลพระภูมิ)
- **ศาลพระภูมิ** – กด F ถวาย พวงมาลัย / น้ำแดง / ไข่ต้ม / หัวหมู (ซื้อที่ร้านป้าติ๋ม) ได้พร EXP/ป้องกัน/เงิน/ของดรอป 20–30 นาที
- **ผีห่าบุกหมู่บ้าน** (server/events.js) – ทุก 30 นาที มีเตือนล่วงหน้า 45 วิ ผี 5 ระลอกเดินจากชายป่าเข้าหาศาลพระภูมิ
  ทุกคนช่วยกันตี (server ถือ HP) · ชนะ = รางวัลตามดาเมจ + แก่นวิญญาณผีห่า · ศาลแตก = ร้านป้าติ๋มปิด 10 นาที
  ทดสอบเร็ว: `EVENT_FIRST_MS=20000 npm start`

## ระบบสกิล 20 แบบ (shared/data/skills.js → skills.json)

| อาชีพ | 1 (Lv.1) | 2 (Lv.2) | 3 (Lv.4) | 4 (Lv.6) | ★ อัลติเมต (Lv.8) |
|---|---|---|---|---|---|
| จอมขมังเวทย์ | คาถาอาคม | ยันต์ตรึงวิญญาณ (ตรึง) | เกราะยันต์เก้ายอด | อัสนีบาต | เพลิงกัลป์ปราบผี |
| นักมวยคาดเชือก | หมัดแย็บ | เตะก้านคอ (มึนงง) | จระเข้ฟาดหาง | ไหว้ครูรำมวย | หักงวงไอยรา |
| ขุนศึก | ฟันดาบคู่ | แทงทะลวง | ดาบวายุ | ตั้งการ์ดดาบคู่ | เพลงดาบพิฆาต |
| พรานป่า | ศรฉับไว | ศรพิษพรานไพร (พิษ) | ศรทะลวงเกราะ | ตาเหยี่ยว | ห่าฝนธนู |

- ได้ 1 SP ต่อเลเวล สกิลละ 5 เลเวล (ดาเมจ +15% · คูลดาวน์ −4% · MP +10% ต่อเลเวล)
- อัปสกิลเลเวลถัดไปต้องมีเลเวลตัวละคร = เลเวลปลดล็อก + 2 × (เลเวลสกิล − 1)
- กด K → กด **+** เพื่อเรียน/อัป, **ลากไอคอน** ไปวางช่อง Q W E R T หรือ **คลิกปุ่มตัวอักษร** เพื่อติดตั้ง, คลิกขวาที่ช่องเพื่อถอด
- สร้าง `skills.json` ใหม่หลังแก้ข้อมูล: `node tools/export_skills.mjs`
- ออนไลน์: ใช้สกิล → `skill:cast` → server ตรวจอาชีพ/ตำแหน่ง/ความถี่ → ส่งให้ผู้เล่นอื่นแสดง VFX

## เสียง (client/js/systems/Sound.js)

เสียงทั้งหมดสังเคราะห์สดด้วย Web Audio ไม่ต้องมีไฟล์เสียง
- เสียงเอฟเฟกต์: ฟัน ยิง ต่อย สกิล โดนตี คริติคอล ผีตาย เก็บเงิน เลเวลอัป ซื้อของ ฯลฯ
- เพลงหลายชั้น (ระนาด · ฆ้องวง · ปี่ · ซอ · pad · เบส + กลองโทน/กลองใหญ่/ฉิ่ง/ฉาบ) 3 เพลง: หมู่บ้าน / ป่าผีดุ / เรดบอส (เปลี่ยนแบบ fade)
- เสียงบรรยากาศ: นกร้องในหมู่บ้าน, จิ้งหรีด-นกฮูก-ลมในป่า, ฟ้าคำรามในลานบอส · เสียงฝีเท้า/ลงพื้น/เปิด-ปิดหน้าต่าง/คำเชิญ
- ปรับระดับเสียง/เปิด-ปิด BGM และ SFX ได้ในหน้าตั้งค่า (Esc) พร้อมตัวเลือกเต็มจอ ตัวเลขดาเมจ และมินิแมป

## ภาพจาก PixelLab

ผี 10 ตัวและ NPC ป้าติ๋มสร้างด้วย PixelLab (โมเดล Pixen, มุมมอง side, พื้นหลังโปร่งใส)
- ภาพต้นฉบับ: `assets_src/pixellab/*.png`
- แปลงเป็น spritesheet พร้อมท่าทาง: `python tools/build_sprites.py` → `client/assets/` + `manifest.json`
- เกมโหลดตาม `manifest.json` อัตโนมัติ ภาพไหนไม่มีไฟล์จะใช้ภาพที่วาดด้วยโค้ดแทน
- ตัวละครผู้เล่น 8 แบบ (4 อาชีพ × ชาย/หญิง) ชุดไทยตามอาชีพ จาก PixelLab อยู่ที่ `client/assets/players/` (ชุดเก่าเก็บไว้ที่ `assets_src/pixellab/players_v1/`)
  ท่าทางสร้างด้วยโค้ด: หายใจ 6 เฟรม, เดิน 8 เฟรม (เหวี่ยงขา/โน้มตัว/เด้ง), โจมตี 6 เฟรมแยกตามอาวุธ, โดนตี 3, ตาย 6, กระโดด 2
- ฉากเมือง: วัด เรือนไทย ศาลา แผงตลาด ศาลพระภูมิ เส้นขอบฟ้าเมือง (`assets_src/pixellab/env/`) และบอส (`assets_src/pixellab/bosses/`)
  ภาพต้นฉบับใส่ชุดสีบานเย็นและผมสีฟ้าเป็น "สีคีย์" เกมจะย้อมเป็นสีชุด/สีผมที่ผู้เล่นเลือก (`client/js/gfx/PlayerArt.js`)

## ใช้ภาพจาก PixelLab เพิ่มเติม

ตอนนี้ภาพทั้งหมดวาดด้วยโค้ดใน `client/js/gfx/` จึงรันได้ทันทีโดยไม่ต้องมีไฟล์ภาพ ถ้าจะเปลี่ยนเป็นภาพจาก PixelLab:

1. ให้ spritesheet เรียงเฟรมเป็นแถวเดียวตามลำดับใน `CHAR_ANIMS` หรือ `MONSTER_ANIMS`
   (เช่น ผี: walk 4 เฟรม → attack 3 → hit 1 → die 4)
2. วางไฟล์ไว้ใน `client/assets/` แล้วโหลดใน `BootScene.preload()`
3. สร้าง animation key ชื่อเดิม (`mon_krasue:walk` ฯลฯ) แทนการเรียก `bakeMonster()` ส่วนโค้ดอื่นไม่ต้องแก้
