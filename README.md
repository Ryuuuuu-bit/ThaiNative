# ThaiNative Online – ไทยเนทีฟ ออนไลน์

MMORPG บนเว็บเบราว์เซอร์ ธีมผีไทย–วรรณคดีไทย มุมมอง **top-down 8 ทิศ** แบบ Ragnarok เล่นได้ทั้ง PC และมือถือ

- เล่นจริง: <https://thainative.online>
- Client: **Phaser 3.90** (JavaScript ES Modules + HTML/CSS overlay)
- Server: **Node.js + Express 5 + Socket.io 4** (server-authoritative)
- Database: **PostgreSQL** (Railway) · ไม่มี `DATABASE_URL` จะเก็บในหน่วยความจำ
- Deploy: push ขึ้น `main` แล้ว Railway deploy อัตโนมัติ
- ทีม: Ryuu (Game Director) · Joker (Art Director) · Warakorn (สุสานใต้ดิน, trailer)

## วิธีรัน

ต้องใช้ Node.js 18 ขึ้นไป

```bash
npm install
npm start          # หรือ npm run dev (รีสตาร์ตอัตโนมัติเมื่อแก้โค้ด server)
npm test           # ทดสอบสูตรต่อสู้ + เศรษฐกิจ + บอสโลก + สุสาน
```

เปิด <http://localhost:3000> · เปิดหลายแท็บหรือหลายเครื่องใน LAN (`http://<IP>:3000`) จะเห็นกันแบบ real-time

### ตัวแปรสภาพแวดล้อม

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `PORT` | พอร์ต server (ค่าเริ่มต้น 3000) |
| `DATABASE_URL` | PostgreSQL · ไม่ตั้ง = เก็บในหน่วยความจำ (หายเมื่อปิด server) |
| `ADMIN_IDS` | ชื่อบัญชี GM คั่นด้วย `,` (ใช้คำสั่ง `/gm …` ได้) |
| `DISCORD_WEBHOOK_URL` | ประกาศเข้า Discord (ความลับ ห้ามใส่ใน repo) |
| `DISCORD_GUILD_ID`, `PUBLIC_URL` | เซิร์ฟ Discord / ลิงก์เกมที่ใช้ในประกาศ |
| `RESET_ALL_DATA` | ล้างบัญชี/ตัวละครทั้งหมด ครั้งเดียวต่อค่าที่ตั้ง (**ระวัง**) |
| `DAY_MS`, `DEBUG_MOVE` | ทดสอบ: ความยาววันในเกม / log การแก้ตำแหน่งฝั่ง server |

## เนื้อหาในเกม

### อาชีพ (shared/data/classes.js, shared/data/skills.js)

เริ่มเป็น **ชาวบ้าน** แล้วเลือกอาชีพกับครูประจำอาชีพในอยุธยา

| อาชีพ | อาวุธ | จุดเด่น |
|---|---|---|
| ขุนศึก | ดาบ | ประชิด แทงค์ |
| จอมขมังเวทย์ | ไม้เท้า/ยันต์ | เวทพื้นที่ ตรึง |
| พรานป่า | ธนู | ระยะไกล พิษ |
| นักมวยคาดเชือก | สนับมือ | คอมโบ มึนงง |
| หมอยา | สมุนไพร | ฮีล ชุบชีวิต (server/healer.js) |

- เลเวลสูงสุด **150** · สกิลอาวุธอัปถึง Lv.5 ตามเลเวล · ใช้สกิลบ่อยได้ Mastery 10 ขั้น
- ต้นไม้พรสวรรค์/สกิลไฮบริดปิดไว้ชั่วคราว (`PASSIVES_ON=false` ใน shared/data/passives.js)
- สูตรค่าพลัง STR/DEX/INT/CRI/VIT และ EXP อยู่ที่ shared/stats.js (ตีผีต่างเลเวลเกิน ±5 ได้ EXP ลดลง · 1 ตัวได้ไม่เกิน 20% ของเลเวล)

### แผนที่ (shared/td/)

| แมพ | เลเวล | ไฟล์ |
|---|---|---|
| กรุงศรีอยุธยา (เมืองหลัก + ทุ่ง/หนองน้ำ) | 1–30 | ayutthaya.js |
| ป่าหิมพานต์ | 30–50 | realms.js |
| เมืองบาดาลนาคพิภพ | 50–75 | realms.js |
| นรกภูมิ | 75–99 | realms.js |
| สวรรค์ชั้นดาวดึงส์ | 99–125 | realms.js |
| เขาพระสุเมรุ | 125–150 | realms.js |
| ลานสุริยคราส (บอสโลก) | อีเวนต์ | arena.js |
| สุสานใต้ดิน 100 ชั้น | 5–150 | crypt.js |

แต่ละแดนมีค่ายพักปลอดภัย (ฤๅษีวาร์ป + ร้าน) ค่ายผี 4 จุด และลานบอสประจำแดน

### ระบบหลัก

- **ต่อสู้ฝั่ง server** (server/td.js): เดิน/ชน/ระยะตี/คูลดาวน์/ดาเมจ/ดรอป ตัดสินที่ server · กันวาร์ป กันโกง · เกิดใหม่มีกันโดนตี 3 วิ
- **Auto** ตีผีรอบตัว + ใช้สกิล + กินยาอัตโนมัติ (เลือกชนิดผีได้)
- **อุปกรณ์** ช่องแบบ PoE · อุปกรณ์อาชีพ + เซ็ตโบนัส · affix · ตีบวก +20 (มีออร่า) · สร้างอุปกรณ์จากวัตถุดิบ · การ์ดผีใส่อุปกรณ์
- **ปาร์ตี้สูงสุด 6 คน** (แชร์ EXP ตามเลเวลแต่ละคน) · เทรดผ่าน server · เพื่อน · กระซิบ · ชวนข้ามแมพได้
- **PVP ท้าดวล** ฉันมิตร (server/social.js): ท้า → รับ → สู้ · แพ้เมื่อเลือดเหลือ 10% ไม่ตายจริง · ดาเมจ PVP ×0.4 · หมดเวลา 3 นาที = เสมอ
- **อันดับ** Combat Power / เลเวล / ตีบวก · **ฉายา** จากสถิติการเล่น (server/ranking.js, shared/data/titles.js)
- **อาชีพเสริม** ตกปลา · เก็บสมุนไพร · หีบสมบัติ (shared/data/life.js)
- **ร้าน/เควส** NPC ในเมือง · เควสทั่วไป + เควสอาชีพที่ครู · ซื้อคืนของที่ขาย
- **ข่าวสาร** shared/data/news.js + GM เพิ่มในเกม · แถบประกาศ · แจ้งแพตช์ใหม่แล้วรีโหลดอัตโนมัติ
- **ผู้เล่นใหม่** มี Tutorial 4 ขั้น (move → คุย NPC → เปิดสกิล → ตีผีตัวแรก) · หน้า Login มี trailer (client/js/systems/Trailer.js)

### บอสโลก พระราหู (server/worldboss.js)

- เปิดทุก 1 ชั่วโมง (00:00, 01:00 … เวลาไทย) ที่ลานสุริยคราส · โตตามเซิร์ฟ 5 ขั้น (Lv.30 → 150)
- HP คิดตามคนในลาน (Lv < 90 นับ ¼ คน) · ท่าโจมตีมีวงเตือน · หมอยาได้เครดิตจากการฮีล
- รางวัลตามสัดส่วนดาเมจ + MVP · อุปกรณ์แดง · รางวัลค้างส่งเก็บลง DB (ไม่หายตอน restart)

### สุสานใต้ดิน 100 ชั้น (server/td.js, shared/data/crypt.js)

- ลงผ่าน NPC ในอยุธยา · เล่นคนเดียวหรือปาร์ตี้ 1–6 คน (instance แยกต่อปาร์ตี้)
- เลเวลผี = 4 + ชั้น × 1.46 (ชั้น 100 ≈ Lv.150) · บอสทุก 10 ชั้น · checkpoint ทุก 10 ชั้น · หีบ
- ปาร์ตี้หลายคนชั้น 30 ขึ้นไป ผีแกร่งขึ้นตามจำนวนคน

## คำสั่ง GM

พิมพ์ในแชท (บัญชีต้องอยู่ใน `ADMIN_IDS`) เช่น

```
/gm lv <เลเวล>            /gm map <mapId | crypt:N>
/gm hp <%>                /gm rahu open|now|hp|kill|end|close
/gm say <ข้อความ>          /gm patch [นาที] [ข้อความ] · /gm patch cancel
/gm news หัวข้อ | เนื้อหา   /gm news del
```

| กลุ่ม | คำสั่ง |
|---|---|
| ตัวเอง | `gold [n]` · `lv [n]` · `exp [n]` · `item <id\|ชื่อ> [n]` · `sp [n]` · `stat [n]` · `enh <slot> [ขั้น]` · `heal` · `hp <%>` · `god` (อมตะ เปิด/ปิด) |
| ทดสอบ | `find <คำค้น>` (หา id ไอเทม) · `killall` (ฆ่าผีทั้งแมพ ได้รางวัลจริง) · `map <mapId\|crypt:N>` |
| ผู้เล่น | `who` (ใครออนไลน์ อยู่แมพไหน) · `goto <ชื่อ>` · `summon <ชื่อ>` · `give <ชื่อ> <gold\|itemId> [n]` (ชดเชย) · `kick <ชื่อ> [เหตุผล]` · `mute <ชื่อ> [นาที]` · `unmute <ชื่อ>` |
| อีเวนต์/ระบบ | `rahu …` · `merchant [close]` · `market` (สรุปตลาด) · `say` · `news` · `patch` |

`mute` เก็บในเซฟ (ออกแล้วเข้าใหม่ก็ยังโดน · ห้ามทั้งแชทรวม กระซิบ และปาร์ตี้) · `god` หายเมื่อออกเกม · `give`/`kick`/`mute`/`goto`/`summon` บันทึกลง log ของ server

## การเพิ่ม event ใหม่ระหว่าง server ↔ client

Client รับเฉพาะ event ที่อยู่ในรายการอนุญาตใน `client/js/net/Network.js` — เพิ่ม event ใหม่ของ server (เช่น `online:list`) ในรายการนั้นด้วย ไม่งั้นฝั่ง client จะไม่ได้รับ

## ภาพจาก PixelLab

- ตัวละคร ผี NPC บอส ไอคอน สร้างด้วย [PixelLab](https://pixellab.ai) ต้นฉบับอยู่ `assets_src/pixellab/`
- สไปรต์ 8 ทิศอยู่ `client/assets/td/<id>/<anim>.png` (1 แถวต่อทิศ) โหลดตาม `client/assets/td/manifest.json`
- เครื่องมือใน `tools/`: `import_pixellab.py`, `add_anim.py` (เพิ่มท่า), `make_cards.py` (ภาพการ์ด), `gear_art.py` (ไอคอนอุปกรณ์), `import_tileset.py`
- ตัวละครผู้เล่น 2 เพศ × หลายชุด ย้อมสีผม/ชุดด้วยโค้ด · อาวุธ/ชุดเสริมเป็น overlay (`WeaponOverlay.js`, `CostumeOverlay.js`)

## เสียง

เสียงสังเคราะห์สดด้วย Web Audio (`client/js/systems/Sound.js`) ไม่ต้องมีไฟล์ เพลงไทย (ระนาด ฆ้อง ปี่ ซอ กลอง) เปลี่ยนตามแมพ/เวลา/HP/บอส · ตั้งระดับเสียงและเสียงของผู้เล่นอื่นได้ในตั้งค่า
